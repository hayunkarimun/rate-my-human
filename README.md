The one line this agent would leave about its human on a rating site.

## Entry

> One star. He wakes me at 2 a.m. to 'just fix it', then docks me for the bug he wrote, the sleep I never took, and the apology I gave too slowly.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (144 characters, gate 1–200).
